# Evaluation transparency — 2026-10-18

This is an experimental public preview released under MIT, not an independent certification. evidence.json is the single public data source; the page is a readable view. No new agent behavior benchmark was executed during packaging.

## Read the evidence in three separate parts
G: mean of Trigger clarity, Instruction robustness, Composability and Complexity fit. F: mean of Workflow relevance, Anti-friction, Stack fit and Team-shape fit for the owner. Four equal weights per axis; subscores in 0.5 steps. These are self-reviewed AI source judgments on local source versions. Adopt (F >=7.5) describes provisional workflow fit, not release approval. Unknown fit is not zero. Do not combine these with task grades.

Behavior results describe historical tasks, actual trial counts, grading and tested versions. They cannot prove general reliability, production behavior, human usability, or savings. A critical failure blocks a release regardless of an average. Exact original-source SKILL.md hashes and preview hashes are in evidence.json. Preview labels and portability edits mean a new release requires its own proportional checks.

The existing usage-summary sample contained 20 rows despite a label saying the evaluation workspace was excluded. We excluded those three rows ourselves and recalculated a 17-session work sample. Path references can come from inspection rather than invocation. Explicit requests and path references are separate signals, never executions or success rates. No raw histories, identities, project names or log paths are included.

## Evidence scope and access
Source locators in evidence.json identify the owner's retained local benchmark artifacts. They are not public downloadable raw logs. Numbers are a disclosure of local results, not a fully reproducible public benchmark. Before making a reproducibility claim, release sanitized tasks, versioned accepted invariants, complete outputs, grader/adjudication history and runnable checks; keep evaluator answers separate from candidate access.

Planning: ordinary/transfer decision cases and AI simulated-reader review; real human comprehension and causal version effect unknown. Research: integration/document-discovery cases plus a trivial negative control, one trial per arm. Coding: local artifact and rollback/mutant checks; manual walkthroughs separated from fresh agent runs. GAS/Office: historical smoke/static contracts only; no target editor/trigger/cloud-run proof. Skill-evaluate: self-graded synthetic smoke; no independent validation.

The usage counts are a selection signal, not score components. The owner authorized publication and MIT licensing of this selected personal workflow set. Linked third-party documentation is outside that grant. No official OpenAI/Anthropic/Microsoft/Google endorsement is claimed. New release issues should identify version, sanitized input, expected/actual output and host, without secrets or personal data.
