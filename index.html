  • ตรวจ caller และจุดที่ใช้ร่วมกัน
  • เลือกการแก้ที่เล็กและตรงต้นเหตุ
  • ทิ้งวิธีตรวจซ้ำสำหรับ logic สำคัญ

ตรวจ Apps Script ก่อนเจอปัญหาตอนรัน

เขียน Google Apps Script แล้วอยากตรวจอีกชั้น?

ให้ AI ตรวจ API ของ Apps Script รูปร่าง event ข้อมูลว่าง และ log ที่อาจมีข้อมูลลับ พร้อมแยกสิ่งที่ต้องไปลองในระบบจริง

  • แยก event ของ Forms กับ Sheets
  • จับการเรียก API ผิด host
  • ชี้ข้อมูลที่ควรตรวจใน log

  1. เลือกและอ่านก่อนเปิดวิธีใช้ ดูขอบเขตและตัวอย่าง แล้วดาวน์โหลด ZIP ของงานที่ต้องการ
  2. เพิ่มให้ agent ที่ใช้แตก ZIP เก็บโฟลเดอร์และไฟล์ประกอบไว้ด้วยกัน แล้วเพิ่มในตำแหน่ง Skills ตามที่ agent รองรับ
  3. ลองกับงานจำลองคัดลอกคำสั่งตัวอย่าง เรียกชื่อ skill และตรวจผลลัพธ์ก่อนใช้ข้อมูลจริง
ก่อนเชื่อคะแนน อยากรู้ว่าเราประเมินอย่างไร?

G คือคุณภาพคำสั่ง ส่วน F คือความเหมาะกับงานของเจ้าของเว็บ ทั้งสองเป็นการอ่าน source โดย AI ที่ช่วยผู้พัฒนา ไม่ใช่ certification อิสระ F สูงจึงไม่ได้แปลว่าเหมาะกับทุกคน

ผลทำโจทย์จริงแยกจาก G/F และระบุรุ่น จำนวน trials ผู้ตรวจ และข้อจำกัด คะแนนเต็มใน sample เล็กไม่ใช่อัตราสำเร็จทั่วไป Public previews มีการปรับให้พกพาได้ จึงไม่รับคะแนนพฤติกรรมของรุ่น local โดยอัตโนมัติ

sample การอ้างถึงเดิมวันที่ 4 ต.ค. เหลือ 17 work sessions หลังตัดงานประเมิน 3 sessions ออก ไม่ใช่จำนวนใช้สำเร็จหรือข้อมูลทุกบัญชี ยังไม่มีหลักฐานผลประหยัดเวลา/token หรือการทดสอบความเข้าใจของผู้ใช้จริง

ใช้ฟรีแค่ไหน?

เว็บแอปและไฟล์ Skills ที่แจกในหน้านี้เปิดใช้หรือดาวน์โหลดได้ฟรี ส่วน AI agent, model หรือบริการภายนอกที่คุณเลือกใช้อาจมีค่าใช้จ่ายตามเงื่อนไขของบริการนั้น

Skill ต่างจาก prompt ทั่วไปอย่างไร?

Skill รวมคำแนะนำ วิธีตรวจงาน และไฟล์อ้างอิงให้เรียกใช้ซ้ำตามงาน ส่วน prompt คือคำขอของงานรอบนั้น ตัวอย่างบนหน้านี้ใช้เริ่มบทสนทนาหลังเพิ่ม skill แล้ว ไม่ได้แทนไฟล์ทั้งแพ็กเกจ

ใช้กับ AI ทุกตัวได้เลยไหม?

ต้องใช้ agent หรือ host ที่รองรับรูปแบบ Skills และเครื่องมือที่งานนั้นต้องใช้ ตำแหน่งติดตั้งและการเรียกใช้ขึ้นกับ host อ่าน README ของแพ็กเกจก่อน และเริ่มจากงานจำลอง

ใช้กับงานจริงได้ไหม?

เลือกตามขอบเขตงานและตรวจผลก่อนใช้ Skills ยังเป็น public previews; การตรวจคำสั่งหรือทดสอบในเครื่องไม่ได้รับรองผลบนทุกระบบ งาน Apps Script, Excel และ Power Automate ยังต้องตรวจบน host และข้อมูลที่เกี่ยวข้องจริง
